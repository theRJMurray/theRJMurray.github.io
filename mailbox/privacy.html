mailbox privacy policy

Last updated October 28, 2026

mailbox is a personal tool that runs on the user's own computer. This policy explains what it does with Google user data.

What it accesses

With the Gmail permission the user grants (gmail.modify), mailbox can read messages and labels, create drafts, change labels, and send drafts in the Gmail accounts the user signs in. It reads the account's email address to tell accounts apart.

Where data is kept

The sign-in tokens Google issues are stored only in a folder in the user's own profile on their computer. Attachments the user asks to save are written to a folder on that same computer. mailbox has no server, no database and no analytics, and the developer receives none of this data.

How data is used

Email is fetched only when the user asks their AI assistant (Claude Code, made by Anthropic) to do something with their mail. The parts of a message needed to answer are passed to that assistant within the user's own session, under the user's own agreement with Anthropic. mailbox does not sell data, does not use it for advertising, and does not use it to train AI models. Nothing is sent from the user's account unless the user clicks Send it in a confirmation window on their screen.

Sharing

mailbox shares Google user data with no one other than the AI assistant the user is running, as described above.

Limited Use

mailbox's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The user can remove mailbox's access at any time at myaccount.google.com/permissions, or with the remove command, which also deletes the stored token.
