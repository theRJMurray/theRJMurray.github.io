mailbox

mailbox is a small program I wrote for my own use. It runs on my own computer and lets the AI assistant I use (Claude Code) search, read, label and draft email in my own Gmail accounts, so I can manage several inboxes in one place.

It is not a public service. There is no website to sign up on and no server: the program and everything it stores stay on the computer it runs on.

What it can do

  • Search and read mail in the accounts I sign in.
  • Save drafts and change labels (archive, mark read, star).
  • Send a draft only after I click Send it in a confirmation window on my screen.
